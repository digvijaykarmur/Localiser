# Fonts

Drop these SIL-OFL Devanagari fonts here (all free on Google Fonts — safe to bundle):

- `Mukta-Regular.ttf`, `Mukta-SemiBold.ttf`, `Mukta-ExtraBold.ttf`
- `Kalam-Regular.ttf`, `Kalam-Bold.ttf`
- `YatraOne-Regular.ttf`
- `Baloo2-Regular.ttf`

`python -m localiser.cli doctor` verifies each file has Devanagari coverage
(conjuncts + matras) before any typesetting run.
